## 尚需跨设备局域网验证

云端测试不包含真实手机和 Windows 电脑接入同一 Wi-Fi / 热点，以下项目不能视为已通过：

| 场景 | 验收标准 |
| --- | --- |
| Android + Android + iOS | 三人发现、加入并完成叫分、出牌、结算，画面一致 |
| Windows + Android + iOS | 手机 / 电脑分别作为房主，完成发现、加入和完整对局 |
| Windows 防火墙 | 专用网络许可后可作为房主，手动地址加入可用 |
| iOS 房主 | iOS 创建，Android 发现并加入 |
| 无外网 Wi-Fi | 路由器断开 WAN、手机关闭移动数据后完成一局 |
| 手机热点 | 房主位于热点手机 / 其他手机两种情况均测，需设备支持无外网局域网互通 |
| mDNS 被阻止 | 未开启客户端隔离时手动 IP:端口可用 |
| 权限拒绝 | 有清晰提示，授权后刷新恢复 |
| 客户端后台 | 暂停后 60 秒内恢复原手牌与轮次 |
| 房主后台 | 60 秒内恢复继续，超过 60 秒结束且不计分 |
| 杀死房主 | 检测断线、重连超时，可回到首页 |
| 屏幕与系统 | 安全区域、手势导航、字体放大、iPad 横屏 |

不包含后台常驻服务或房主迁移，不承诺在系统杀进程后恢复。纯 Dart / Socket 测试不能证明跨设备 Bonjour / Windows DNS-SD / Android NSD 或热点的实际行为。
