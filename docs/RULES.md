# 首版规则

## 发牌与叫分

- 一副 54 张牌，三位真人每人 17 张，留下 3 张底牌。
- 随机选择第一位叫分玩家，按座位循环。每人叫一次：不叫、1 分、2 分、3 分；叫分必须高于之前的最高分。
- 叫 3 分立即成为地主；否则三人都叫完后，最高分者成为地主。全员不叫，重发并轮换第一位叫分玩家。
- 地主拿底牌并先出。按座位依次出牌，每次必须压过上一手；连续两家不出后清空本轮，最后出牌者重新领出。领出者不能不出。
- 地主先出完则地主胜；任意一名农民先出完则农民共同获胜。

## 牌型

大小：3 < 4 < … < 10 < J < Q < K < A < 2 < 小王 < 大王。花色不影响比较。

| 牌型 | 约定 |
| --- | --- |
| 单张、对子、三张 | 比较牌面大小 |
| 三带一 / 三带一对 | 带牌与三张不同点数，比较三张 |
| 顺子 | 至少 5 张连续单牌，不能包含 2 或王 |
| 连对 | 至少 3 个连续对子，不能包含 2 或王 |
| 飞机 | 至少 2 个连续的三张，主体不能包含 2 或王 |
| 飞机带单 | 每个主体带一张；单翅可以组成对子，同点数最多 2 张；不能与主体同点数 |
| 飞机带对 | 每个主体带一个不同点数的对子；不能与主体同点数 |
| 四带二 | 四张同点数带两张，带牌可以是对子，也可以是大小王 |
| 四带两对 | 四张同点数带两个不同点数的对子；两副炸弹不算此牌型 |
| 炸弹 | 四张同点数，压过普通牌型；炸弹间比较点数 |
| 王炸 | 大小王，最大；不能压过另一手王炸 |

普通牌型必须类型与张数相同才可比较，顺子、连对、飞机按主体最高点数比较。提示提供各合法主体的代表性组合，不承诺最优策略，也不会自动出牌。

## 计分

`单位分 = 地主叫分 × 倍数`。初始倍数为 1，每个炸弹或王炸 ×2，春天或反春天再 ×2。

- 地主胜：地主 +2 单位分，两名农民各 -1 单位分。
- 农民胜：地主 -2 单位分，两名农民各 +1 单位分。
- 春天：地主胜且两位农民都没有出过牌。
- 反春天：农民胜且地主只出过一手牌。
- 每局积分之和为零。断线超时、玩家主动退出而中止的局不改变积分。
- 已结算积分保留在当前房间中，重新准备可继续下一局。
